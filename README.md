security labs completed as part of coursework.

I’m solving these labs as part of my journey to learn mobile security, so this repo
is also a record of my progress and understanding along the way.

**Feedback welcome:** Feel free to open an issue, send feedback, or reach out if
something is wrong, unclear, or could be improved. I’m still learning, so corrections
and suggestions are appreciated.

**Disclaimer:** This repository is for educational purposes only. It is not intended
for testing systems without explicit authorization. Do not use these materials
against any system you do not own or have written permission to test.
